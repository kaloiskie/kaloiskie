## 👋 About

Full-stack developer and IT operations professional with **4+ years** building and running production systems for a licensed lottery operator in the Philippines. I work from database schema to deployment — React and Vite on the front, Express/Node and PostgreSQL behind it, on Ubuntu servers I also operate.

Day to day I build real-time gaming dashboards, async queue layers with bounded concurrency, Telegram bot ecosystems, and Android MDM tooling. Currently **IT Supervisor at Northman Gaming Corporation**, leading a two-person IT team.

> Looking for remote backend or full-stack roles where infrastructure, performance, and reliability actually matter.
